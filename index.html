Sobre mí

Perfil profesional

Me interesa crear soluciones digitales que combinen funcionalidad, diseño y una buena experiencia de usuario. Disfruto trabajar en el desarrollo web, especialmente en la creación de interfaces claras, modernas y fáciles de utilizar.

Cada proyecto es una oportunidad para convertir conocimientos en experiencia. A través de proyectos universitarios y personales he fortalecido mis habilidades en HTML, CSS, JavaScript y Python, aplicando buenas prácticas de programación, organización del código y control de versiones con Git. Mi enfoque es seguir aprendiendo, experimentar con nuevas tecnologías y mejorar en cada proyecto.

  • Portafolio personal

    Sitio web responsive con tema claro/oscuro, filtro de proyectos y un Design System documentado.

    • CSS3
    • JavaScript
    Código
    • Estructura con HTML5 semántico y jerarquía correcta de encabezados.
    • Estilos organizados con design tokens (CSS Custom Properties).
    • Tema claro/oscuro con preferencia guardada en localStorage.
    • Filtro de proyectos, modal de detalle y validación de formulario.

    Aprendí a planificar un sistema de diseño antes de escribir estilos y a mantener el proyecto con commits frecuentes.

  • PARKING CONTROL BY AVAILABLE SPACES

    Aplicación web para gestionar estacionamientos, registrar vehículos y usuarios, consultar espacios disponibles y monitorear el estado del parking en tiempo real.

    Problema: el control manual causaba confusiones, registros incompletos y dificultad para conocer la disponibilidad de espacios en tiempo real.

    • Python
    • Django
    • SQLite
    • OpenCV / YOLO
    • HTML/CSS/JavaScript
    Código
    • Registro y administración de usuarios y vehículos.
    • Monitoreo de espacios disponibles y detección automática de ocupación con visión artificial.
    • Panel de vigilancia, estadísticas, reportes y visualización del estado del estacionamiento.
    • Interfaz web amigable para la administración y control de entradas y salidas.

    Proyecto práctico que integra bases de datos, lógica de negocio y visión por computadora. Aprendí a modelar datos, conectar el sistema con la interfaz y aplicar soluciones inteligentes para automatizar procesos de control y análisis.

  • Aplicación web para clasificación de escenas con inteligencia artificial

    Aplicación desarrollada con Streamlit para clasificar imágenes de escenarios naturales y urbanos mediante redes neuronales convolucionales. Permite subir una imagen o usar la cámara para reconocer edificios, bosques, glaciares, montañas, mares o calles.

    Problema: facilita reconocer de forma rápida y visual el tipo de paisaje o entorno en una imagen, con resultados interpretables para tareas de análisis de imágenes y visión por computadora.

    • Python
    • Streamlit
    • TensorFlow / Keras
    • OpenCV
    • NumPy
    • Pillow
    • SQLite
    Código
    • Subir imágenes o capturarlas con la cámara y seleccionar entre distintos modelos CNN.
    • Consultar la clase predicha, el nivel de confianza y las probabilidades por categoría.
    • Guardar el historial de clasificaciones, consultar estadísticas y tendencias, y descargar reportes en JSON.

    Aprendí sobre procesamiento de imágenes, redes neuronales convolucionales, entrenamiento y uso de modelos preentrenados, despliegue con Streamlit, integración de una base de datos local y visualización de métricas y resultados.

  • Juego Ahorcado

    Juego de palabras en el que el jugador intenta descubrir la palabra oculta letra por letra antes de quedarse sin intentos.

    Problema: ofrece una forma interactiva de practicar lógica, validación de entradas y control del estado de un juego.

    • Java
    • Swing
    Código
    • Ingresar una palabra y comenzar una partida.
    • Probar letras y consultar aciertos, errores e intentos restantes.
    • Mostrar las letras acertadas, las fallidas y los intentos restantes.

    La partida muestra el estado de la palabra, las letras acertadas y fallidas, y los intentos restantes.
